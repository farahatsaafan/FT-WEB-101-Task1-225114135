## 📌 Project Overview
A responsive and interactive personal profile webpage built using vanilla **HTML5**, **CSS3**, and **JavaScript** without any external libraries or frameworks.

## 🚀 Features
- **Semantic Structure:** Organized cleanly with `<header>`, `<main>`, and `<footer>`.
- **Navigation Bar:** Flexbox header navigation with student name on the left and navigation links on the right.
- **Theme Toggle:** Interactive Light / Dark mode toggle switch using CSS custom variables defined on `:root` and toggled with `body.dark`.
- **Profile Presentation:** Styled circular profile photo with an about description.
- **Card Highlights:** Flexbox row of cards showcasing skills and interests, styled with spacing gap and hover transition effects.
- **Interactive Contact Form:** Name and email inputs paired with corresponding `<label>` tags (`for`/`id` matching), client-side validation, and instant greeting message without reloading the page.
- **Back-to-Top Button:** Smooth-scroll back to top navigation.
- **Responsive Layout:** Optimized for mobile, tablet, and desktop viewports with `box-sizing: border-box`.
